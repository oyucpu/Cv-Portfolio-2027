📋 Etiquetas HTML 1.0 (1991-1993)

Leyenda: Etiquetas con fondo rojo están OBSOLETAS | Atributos en azul están obsoletos
<html>
Elemento raíz del documento HTML
<head>
Contiene metadatos e información del documento
<title>
Define el título del documento que aparece en la pestaña del navegador
<body>
Contiene todo el contenido visible del documento
<h1> - <h6>
Encabezados de seis niveles diferentes, siendo h1 el más importante
<p>
Define un párrafo de texto
<a>
Crea enlaces o hipervínculos a otras páginas o recursos
href name title
<ul>
Lista desordenada (con viñetas)
compact Especifica que la lista debe mostrarse más pequeña de lo normal.
<ol>
Lista ordenada (numerada)
compact Especifica que la lista debe mostrarse más pequeña de lo normal.
<li>
Elemento individual de una lista
<dl>
Lista de definiciones (glosario)
compact Especifica que la lista debe mostrarse más pequeña de lo normal.
<dt>
Término que se va a definir en una lista de definiciones
<dd>
Descripción o definición del término en una lista de definiciones
<nextid>OBSOLETA
Generaba identificadores únicos. Nunca se implementó correctamente y desapareció rápidamente
n La N es el número de identificadores únicos.
<listing>OBSOLETA
Texto preformateado. Representa el texto sin formato, no hay etiqueta de cierre | Ancho a 132 caracteres.
compact Menos espacio y más junto, booleano.
<plaintext>OBSOLETA
Todo el contenido después de la etiqueta se convertía en texto plano, sin cierre.
<xmp>OBSOLETA
Texto preformateado. Usado para marcar texto
<base>OBSOLETA
Define la URL base para que todas las rutas relativas del documento partan de ella. Debe tener href o target (o ambos). Solo puede existir una etiqueta y debe colocarse dentro de .
href target

📝 Información sobre HTML 1.0:

  • Año: 1991-1993
  • Creador: Tim Berners-Lee en el CERN
  • Características: Versión muy básica con solo 18 etiquetas
  • Propósito: Compartir documentos científicos de forma simple
  • Etiqueta obsoleta: Solo <nextid> está obsoleta
  • Atributos obsoletos: "compact" (usado en listas) y "n" (usado en nextid)

🎯 Nota importante:

HTML 1.0 nunca fue un estándar oficial. Fue la implementación original de Tim Berners-Lee. El primer estándar oficial fue HTML 2.0 en 1995.

📋 Sobre los atributos:

Atributos vigentes:

  • href - Define el destino del enlace
  • name - Crea un ancla dentro del documento
  • title - Proporciona información adicional (tooltip)

Atributos obsoletos (en azul):

  • compact - Intentaba reducir el espaciado en listas. Obsoleto en HTML5, usar CSS
  • n - Usado en la etiqueta nextid para definir el siguiente ID. Obsoleto completamente
